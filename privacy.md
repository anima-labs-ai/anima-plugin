# Privacy

Anima Labs processes agent identity data (email, phone/SMS, voice metadata, vault references) to operate the Service.

**Canonical privacy policy:** [https://useanima.sh/privacy](https://useanima.sh/privacy)

Contact: privacy@useanima.sh

This plugin does not store your `ANIMA_API_KEY`. Clients inject it via `${ANIMA_API_KEY}` / environment variables at connection time.
